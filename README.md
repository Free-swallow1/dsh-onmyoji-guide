## 功能

### 1. 图卡介绍（不是纯文本）

每个式神/御魂/阴阳师都有一张介绍图卡（`data/cards/`，共 353 张）：立绘、面板、技能与升级、词条、御魂参考，暗色卡片风格，`/yys 天照` 直接发图。

### 2. 本地知识库（不联网也能答）

- **277 个式神/英杰**：六星面板（攻击/生命/防御/速度/暴击/暴伤/命中/抵抗）、稀有度、CV、定位标签、黑话别名（“修子哥”“阿离”“高铁”……）
- **全部技能**：鬼火消耗、被动/普攻类型、完整描述、Lv2~Lv5 升级效果、引用的 buff/印记词条原文
- **70 个御魂**：57 普通 + 13 首领，2 件套 / 4 件套效果、获取途径
- **阴阳师/英杰**：晴明、神乐、八百比丘尼、源博雅、源赖光、藤原道长全技能与选择建议
- **机制手册**：伤害公式、暴击与满暴、御魂位置/主属性、速度行动条、效果命中/抵抗、控制驱散、三层克制关系、PVE/PVP、黑话

### 2. 满暴与面板计算

输出式神一律按 **先满暴（面板暴击 100%），再算 攻击 × 暴伤** 的口径，不搞概率学。

```
/yys 算 攻击8000 暴击95 暴伤260
→ 未满暴：还差 5%
→ 当前期望 ×3.470；满暴系数 ×3.600；补满暴 +3.7%
→ 满暴后 攻击×暴伤 = 28800
```

### 3. 网易大神最新攻略（ds.163.com）

```
/yys 攻略 魂土配置
/yys 攻略 魂王
/yys 攻略 真蛇
/yys 攻略 地域鬼王配置
/yys 攻略 斗技阵容
/yys 攻略 道馆 / 逢魔 / 六道之门 / 业原火 / 秘闻 / 结界突破 / 永生之海
/yys 攻略 天照魂土配置        # 式神 + 玩法组合
```

- 自动检索圈子里最新的图文攻略，**优先挑带阵容码的**：直接发「阵容码 + 阵容码二维码」，扫码/复制即可导入；没有阵容码的再发普通图文攻略
- 回复标题、作者、日期、正文摘要、原文链接
- 把攻略里的图片转发到群里（默认最多 2 张，可配置）
- 超过 1 年会标注“可能已过时”；搜不到近期攻略会明确说“按机制给通用思路”，不拿旧配置冒充最新
- 群聊里问“魂土怎么配阵容”“咲耶御魂怎么带”会自动触发

### 4. 看图识别

三层流水线，从准到快：

1. **截图文字**：视觉模型读图里的式神/御魂名，读到就直接按名字查库
2. **本地立绘匹配**：白底内容裁剪 + 16×16 颜色特征，同画作匹配准确率高，双阈值防误判
3. **视觉模型识别 + 官方立绘二次确认**：认错时降级为“看着像 X（置信度一般）”，不硬编

识别成功后直接给该式神的面板、定位、御魂推荐、246 和毕业目标。

### 5. 群白名单

默认**不启用任何群**，第一次使用要在配置里添加自己的群号（或让管理员发 `/yys 加群 群号`）：

- WebUI → 插件 → 阴阳师助手 → 配置 → `group_whitelist` 添加群号（留空则不限制群）
- 群里管理员发 `/yys 加群 群号`

## 安装

### 方式一：WebUI 上传（推荐）

1. 下载 Release 里的 `astrbot_plugin_yys.zip`
2. AstrBot WebUI → 插件 → 安装 → 上传文件

### 方式二：克隆到插件目录

```bash
cd AstrBot/data/plugins
git clone https://github.com/your-name/yys.git astrbot_plugin_yys
```

> 建议把目录名改成 `astrbot_plugin_yys`（与 `metadata.yaml` 的 `name` 一致）。如果仓库名就是 `yys`，也可以直接把克隆下来的目录重命名。

重启 AstrBot 或点击插件页的“重载”。

### 依赖

插件本身不强制第三方依赖，使用 AstrBot 自带的 `aiohttp` / `Pillow`。可选：

```bash
pip install rapidocr_onnxruntime "numpy<2"
```

装完后本地 OCR 也能读截图文字（不装则由视觉模型读）。

## 配置

WebUI → 插件 → 阴阳师助手 → 配置：

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `group_whitelist` | `[]` | 启用的群号列表；留空 = 不启用任何群 |
| `passive_mode` | `keyword` | `keyword` 关键词自动答；`off` 只响应指令 |
| `passive_keywords` | 见 schema | 触发自动回答的关键词 |
| `passive_cooldown` | `6` | 同群自动回答冷却（秒） |
| `enable_image` | `true` | 图片识别开关 |
| `enable_vision` | `true` | 本地匹配失败时调用视觉模型 |
| `enable_ds` | `true` | 网易大神攻略检索开关 |
| `ds_max_images` | `2` | 每条攻略最多转发几张图 |
| `ds_max_qr` | `2` | 有阵容码时最多生成几张二维码 |
| `ds_guide_days` | `400` | 攻略时效（天），超过降权/标注 |
| `ds_cookie` | 空 | 大神 Cookie（可选，游客被拒时用） |
| `max_reply_chars` | `900` | 单条回复最大字数 |
| `allow_private` | `true` | 是否允许私聊使用 |
| `quick_card` | `true` | 简单查询直接回卡片 |

## 开发

数据重建（需要先抓 wiki 原始数据）：

```bash
# 1. 抓 wiki Data 页（需要 Node + playwright-core + Edge）
node tools/scrape_wiki.js

# 2. 生成知识库 JSON
python tools/build_data.py

# 3. 生成图片索引（需要 tools 下载的图片）
python tools/download_images.py
python tools/build_index.py

# 4. 抓大神最新动态（可选）
python tools/fetch_ds.py 6

# 5. 本地冒烟测试（stub 掉 astrbot）
python tools/test_local.py
```

`tools/` 里的脚本默认使用仓库相对路径；`scrape_wiki.js` 需要把灰机 wiki 的 Data 页抓到 `tools/raw/`。

## 已知限制

1. 纯立绘/模型图且没有名字文字时，视觉模型对部分式神会认错，插件会用官图二次确认并降级提示，不硬说。
2. 本地匹配只覆盖“同一张官方画作”，游戏内 3D 模型截图不在覆盖范围。
3. 御魂小图标没有官方图库，御魂识别主要靠截图文字和视觉模型。
4. 大神攻略检索依赖公开接口和搜索引擎，偶尔会遇到验证码；此时自动降级到最近动态语料，搜不到会明说。
5. 攻略相关性是启发式判断，合集/导航类帖子会标注“合集导航”。
