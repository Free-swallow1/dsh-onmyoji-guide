| `data/recommend.json` | 式神御魂推荐 | 社区主流配装整理 |

### 重新生成

```bash
# 1. 抓 wiki Data 页到 tools/raw/（需要 Node + playwright-core + Edge）
node tools/scrape_wiki.js

# 2. 生成 JSON
python tools/build_data.py

# 3. 下载图片并生成索引（可选，index 已随仓库提供）
python tools/download_images.py
python tools/build_index.py
```

## 贡献时的来源标注

提交数据或攻略时，请在 PR 与文件里写清：

- 灰机 wiki 页面 URL 或 Data 页名（如 `Data:Character/556.json`）
- 大神原帖 URL（`https://ds.163.com/feed/<id>/`）+ 作者 + 日期
- 官网/社区原帖 URL + 作者 + 日期
