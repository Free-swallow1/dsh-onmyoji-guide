# 版权与许可审计

> 结论先说：**数据/文档已按 CC BY-NC-SA 3.0 补齐署名、非商业、相同方式共享要求；
> 但游戏美术与技能原文的版权属于网易，无法通过 CC 协议“洗白”，这是所有阴阳师同人项目共有的风险，只能声明非商业、可下架。**

## 一、许可映射

| 内容 | 许可 | 说明 |
| --- | --- | --- |
| `*.py`、`tools/*.js` 代码 | MIT（`LICENSE`） | 可商用、可修改、需保留版权声明 |
| `data/*.json`、`data/*.md`、`docs/*` | CC BY-NC-SA 3.0（`LICENSE-DATA`） | 署名灰机 wiki、非商业、相同方式共享 |
| `data/cards/*.png` 中的文字排版 | 同上 | 本项目整理 |
| `data/cards/*.png` 中的立绘/御魂图 | **不适用 CC**，版权归网易 | 非商业同人展示，权利人可要求下架 |
| 式神技能/传记原文 | **不适用 CC**，版权归网易 | 引自游戏/ wiki，非商业引用 |
| `/yys 攻略` 的大神内容 | 版权归原作者 | 运行时检索展示，保留原文链接，不存入仓库 |
| 字体 | 未分发字体文件 | 图卡用系统字体渲染成位图；未打包字体 |

## 二、CC BY-NC-SA 3.0 三个条件是否满足

- **BY 署名**：`LICENSE-DATA` 写明来源（灰机 wiki 链接）、作者（wiki 贡献者）、
  以及“本项目进行了整理/裁剪/重排”的修改说明。✅
- **NC 非商业**：`LICENSE-DATA` 与 `NOTICE` 明确不得商用；项目本身免费。✅
- **SA 相同方式共享**：衍生数据必须以 CC BY-NC-SA 3.0 或兼容协议发布。✅
- **许可链接/全文**：已提供 deed 与 legalcode 链接。✅

## 三、仍然存在的版权风险（无法用 CC 解决）

1. **游戏美术**：式神立绘、御魂图版权归网易。图卡内嵌了这些图片，
   属于非商业同人展示，但不代表获得授权；权利人可以要求下架。
2. **技能/传记文本**：技能描述、式神简介是游戏文案，版权归网易；
   wiki 的 CC 协议不能覆盖其转载的游戏原文。
3. **网易大神内容**：插件运行时检索并转发攻略文字/图片，版权归原作者；
   仓库不存储，但转发行为仍可能涉及信息网络传播，建议保留原文链接、非商业使用。
4. **商标**：“阴阳师”是网易商标，本项目为非官方工具，已在 README/NOTICE 声明无关联。
5. **字体**：图卡用系统字体（微软雅黑等）渲染成位图，未分发字体文件；
   若严格起见，可用 OFL 字体（如 Noto Sans CJK）重新生成。

## 四、降低风险的做法

- 保持免费、非商业，不接付费问答/广告。
- 保留来源链接与作者信息，注明修改。
- 收到权利人通知后立即删除相关图片/文本（在仓库开 Issue 即可）。
- 需要更保守的发行方式：发布**无图卡版本**（删除 `data/cards/` 中的图片），
  只保留数据与文字。
- 重新生成图卡时可指定开源字体：

```bash
CARD_FONT=/path/NotoSansCJKsc-Regular.otf \
CARD_FONT_BOLD=/path/NotoSansCJKsc-Bold.otf \
python tools/build_cards.py --img-dir tools/img
```

## 五、结论

- 对 **CC BY-NC-SA 3.0**：现已满足署名、非商业、相同方式共享与许可声明要求。
- 对 **游戏素材版权**：无法做到“完全没有版权问题”，只能非商业、署名、可下架；
  这是同人项目的固有限制。若需要零风险，只能移除立绘/御魂图与游戏原文。
