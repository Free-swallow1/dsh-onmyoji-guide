# 使用说明

## 1. 安装

### WebUI 上传

1. 下载 Release 中的 `astrbot_plugin_yys.zip`
2. AstrBot WebUI → 插件 → 安装 → 上传

### 克隆

```bash
cd AstrBot/data/plugins
git clone https://github.com/your-name/yys.git astrbot_plugin_yys
```

重启 AstrBot 或重载插件。

## 2. 配置

WebUI → 插件 → 阴阳师助手 → 配置：

- `group_whitelist`：留空 = 不启用任何群；填自己的群号后，只在该群生效
- `passive_mode`：`keyword` 关键词自动答 / `off` 只响应指令
- `enable_ds`：网易大神攻略检索开关
- `ds_max_images`：每条攻略转发几张图（0 = 只发文字）
- `ds_cookie`：游客被拒时可填浏览器 Cookie；或使用 `/yys 大神登录`

## 3. 指令

| 指令 | 作用 |
| --- | --- |
| `/yys 天照` | 式神面板、技能、御魂推荐、毕业面板 |
| `/yys 技能 天照` | 完整技能描述 |
| `/yys 御魂 破势` | 御魂 2/4 件套 |
| `/yys 阴阳师 晴明` | 主角技能 |
| `/yys 满暴 天照` | 满暴凑法 |
| `/yys 算 攻击8000 暴击95 暴伤260` | 满暴判定/期望/攻击×暴伤 |
| `/yys 评分 暴击8 暴伤12 攻击加成5` | 御魂双暴评分 |
| `/yys 克制 破势` | 克制关系 |
| `/yys 攻略 魂土配置` | 大神最新阵容/配置（带图） |
| `/yys 攻略 天照` | 大神最新式神攻略 |
| `/yys 攻略 天照魂土配置` | 式神 + 玩法组合 |
| `/yys 大神登录` | 管理员扫码登录大神 |
| `/yys 大神状态` | 查看游客/登录态 |
| `/yys 加群 123456789` | 管理员加群 |

## 4. 群内自动应答

命中关键词（御魂、满暴、配装、魂土、真蛇、斗技……）、式神/御魂名，或 @机器人 时自动回答；发式神/御魂图片会自动识别。

## 5. 扫码登录（可选）

游客模式可以读大多数公开攻略。如果接口提示需要登录：

1. 管理员在群里发 `/yys 大神登录`
2. 用网易大神 App 扫码，**并在手机上点“确认登录”**
3. 成功后 Cookie 保存在插件数据目录

也可以用 `/yys 大神登录 cookie <Cookie字符串>` 手动导入。

## 6. 加群

- 第一次使用：WebUI 配置里给 `group_whitelist` 添加自己的群号（留空机器人不会在群里说话）
- 或群管理员发 `/yys 加群 群号`
- `/yys 群列表` 查看当前白名单
